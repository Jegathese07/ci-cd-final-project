# CI/CD Final Project

## Project Name
CI/CD Pipeline Automation using GitHub Actions, Tekton and OpenShift

## Project Description
This project demonstrates the implementation of a Continuous Integration and Continuous Deployment (CI/CD) pipeline.

## Technologies Used
- GitHub
- GitHub Actions
- Tekton
- OpenShift
- YAML
- Linux

## Project Objectives
1. Automate code integration using GitHub Actions.
2. Perform linting and code quality checks.
3. Run automated unit tests.
4. Manage pipeline tasks using Tekton.
5. Deploy the application using OpenShift.

Student

## Conclusion
This project helps understand CI/CD automation and application deployment using DevOps tools.
